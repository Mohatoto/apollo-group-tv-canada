# Apollo Group TV Canada

This is the static frontend recovered from the published Apollo website. It includes the compiled JavaScript, styles, and original images.

## GitHub Pages

Upload the contents of this directory, including `.nojekyll`, to the root of your repository. In **Settings → Pages**, select **Deploy from a branch**, choose your branch and **/ (root)**, then save.

For local preview, run `python3 -m http.server 8000` in this directory and visit `http://localhost:8000/`.

The original custom domain remains in the canonical and social metadata. Subscribe buttons use the original email and Google Forms destinations. The Google Ads tag and Lovable telemetry script are omitted.
